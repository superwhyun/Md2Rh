# Markdown2StyledHTML

마크다운을 스타일링된 HTML 문서로 변환하고 프린트할 수 있는 웹 애플리케이션

## 주요 기능

### 📝 마크다운 에디터
- 실시간 마크다운 편집
- 2칸 탭 들여쓰기 지원
- 드래그앤드롭으로 .md 파일 업로드
- 좌우 패널 독립 스크롤

### 🎨 문서 스타일 관리
- 3가지 기본 스타일 프리셋 (모던, 클래식, 미니멀)
- 모든 마크다운 요소 개별 커스터마이징 가능
- 헤딩 자동 넘버링 (H1~H5 지원)
  - 숫자 (1., 2., 3.)
  - 한글 (가., 나., 다.)
  - 괄호 (1), 2), 3))
  - 로마숫자 (I., II., III.)
  - 한글 괄호 ((가), (나), (다))
  - 숫자 괄호 ((1), (2), (3))
  - 없음
- 폰트 선택 (세리프, 산세리프, 모노스페이스, 한글 폰트)
- 색상 및 배경색 자유 설정

### 📋 리스트 커스터마이징
- **UL (순서없는 목록)**: 5단계 레벨별 개별 설정
  - 커스텀 마커 (□, ○, ▪, ▫, ‣ 등)
  - 폰트 크기/종류/굵기
  - 색상 및 배경색
  - 들여쓰기 간격 및 마커 간격
  - 박스 스타일 옵션 (테두리, 배경색)
- **OL (순서있는 목록)**: ReactMarkdown 기본 처리, 기본 스타일 커스터마이징 가능

### 🖼️ 이미지 지원
- 마크다운 이미지 문법 지원 (`![alt](url)`)
- 자동 크기 조정 (최대 너비 100%)
- 비율 유지

### 📄 A4 페이지 렌더링
- A4 크기 (210mm × 297mm) 기준 렌더링
- 브라우저에서 80% 축소 표시로 가독성 향상
- 10mm 여백 적용

### 🖨️ 프린트 기능
- 브라우저 내장 프린트 기능 활용
- CSS 스타일 완전 보존
- 이미지 Base64 변환으로 프린트 최적화
- 링크 카드 스타일 프린트 지원

### 💾 서식 관리
- **서식 복사**: 기존 서식 복제
- **서식 삭제**: 불필요한 서식 제거 (최소 1개 유지)
- **JSON 내보내기**: 서식을 JSON 파일로 다운로드
- **드래그앤드롭 가져오기**: JSON 파일을 드래그하여 서식 추가
- **실시간 미리보기**: 편집 중 실시간으로 변경사항 확인

### 🔗 링크 카드
- 독립적인 URL을 자동으로 링크 카드로 변환
- 메타데이터 자동 추출 (제목, 설명, 이미지, 사이트명)
- 프린트 시에도 스타일 유지

## 기술 스택
- **Frontend**: Next.js 14.2.16, React 18, TypeScript
- **Styling**: Tailwind CSS, CSS-in-JS
- **UI Components**: Radix UI, Lucide Icons
- **Markdown**: react-markdown, remark-gfm
- **Storage**: LocalStorage (스타일 설정 저장)

## 설치 및 실행
```bash
npm install
npm run dev
```

## 사용법
1. 좌측 패널에 마크다운 입력 또는 .md 파일 드래그앤드롭
2. 문서 스타일 관리자에서 스타일 커스터마이징
3. 우측 미리보기에서 실시간 확인
4. "프린트 하기" 버튼으로 문서 출력

## 서식 내보내기/가져오기
1. **내보내기**: 서식 관리자에서 📥 버튼 클릭 → JSON 파일 다운로드
2. **가져오기**: "새 서식 생성" 카드에 JSON 파일 드래그앤드롭

## 지원되는 마크다운 요소
- 제목 (H1~H6) + 자동 넘버링
- 본문 텍스트 + 스타일링
- **굵게**, *기울임*, `인라인 코드`
- 코드 블록 (```)
- 순서없는 목록 (5단계 커스터마이징)
- 순서있는 목록 (기본 스타일)
- 인용문
- 링크
- 이미지
- 테이블
- 링크 카드 (독립 URL 자동 변환)
