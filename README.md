# MD2RD (Markdown to Rendered Document)

마크다운을 스타일링된 문서로 변환하고 PDF로 출력하는 웹 애플리케이션

## 주요 기능

### 📝 마크다운 에디터
- 실시간 마크다운 편집
- 2칸 탭 들여쓰기 지원
- 드래그앤드롭으로 .md 파일 업로드
- 좌우 패널 독립 스크롤

### 🎨 문서 스타일 관리
- 4가지 기본 스타일 프리셋 제공
- 모든 마크다운 요소 개별 커스터마이징
- 헤딩 자동 넘버링 (숫자, 한글, 괄호, 로마숫자, 없음)
- 폰트 선택 (세리프, 산세리프, 모노스페이스)

### 📋 리스트 커스터마이징
- **UL (순서없는 목록)**: 5단계 레벨별 개별 설정
  - 커스텀 마커 (•, ◦, ▪, ▫, ‣ 등)
  - 폰트 크기/종류/굵기
  - 색상 및 배경색
  - 들여쓰기 간격
  - 박스 스타일 옵션
- **OL (순서있는 목록)**: 기본 브라우저 스타일 사용

### 📄 A4 페이지 렌더링
- A4 크기 (210mm × 297mm) 기준 렌더링
- 브라우저에서 80% 축소 표시로 가독성 향상
- CSS 페이지 분할 규칙 적용
- 텍스트가 페이지 경계에서 잘리지 않도록 자동 처리

### 📥 PDF 변환
- html2pdf.js 기반 고품질 PDF 생성
- 브라우저와 PDF 여백 일관성 유지
- 자동 페이지 분할 및 번호 매기기
- CSS 페이지 브레이크 규칙 지원

## 기술 스택
- **Frontend**: Next.js 14.2.16, React 18, TypeScript
- **Styling**: Tailwind CSS, CSS-in-JS
- **UI Components**: Radix UI
- **Markdown**: react-markdown
- **PDF**: html2pdf.js
- **Storage**: LocalStorage (스타일 설정 저장)

## 설치 및 실행
```bash
npm install
npm run dev
```

## 사용법
1. 좌측 패널에 마크다운 입력 또는 .md 파일 드래그앤드롭
2. 문서서식관리자에서 스타일 커스터마이징
3. 우측 미리보기에서 실시간 확인
4. PDF 다운로드 버튼으로 문서 내보내기
